WPF + Fluent UI，支持系统亮暗主题、窗口拖动和完整标题栏；长对话独立滚动，输入区始终固定。

skills · zip

可扩展技能库

5 个领域技能开箱即用，也能从 URL 或本地 ZIP 安装；说明与 C# 模板按需加载，不挤占基础上下文。

csv · excel

模型目录直接交付

表格结果导出为 Excel 友好的 UTF-8 BOM CSV；相对路径自动落到模型目录，多模型自动增加 Model 列。

batch

多模型批量

一个目录下多个 .rvt 在同一 Revit 会话中顺序执行，引擎只初始化一次，单模型失败不影响其他模型。

2019 – 2022

多版本无头执行

支持 Revit 2019–2022，无需打开 Revit 主界面；执行器按安装版本定位真实 Revit API。

agent · roslyn

代码现场生成

智能体生成现代 C#，Roslyn 即时编译并在模型副本上执行；推理、工具调用与结果在界面中实时呈现。
